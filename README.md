## Software Engineer · Frontend → Full-Stack

I've been building products professionally since 2022 as a Frontend Software Development Specialist at [Monster Notebook](https://www.monsternotebook.com.tr/) — storefronts, a customer-support platform, internal tools, a React Native app used by 10,000+ monthly users, and the company's shared component library. Before that, I co-founded a startup while still at university. I'm now growing towards full-stack work, and I build side projects with an agent-first (Claude Code) workflow.

- 🌍  I'm based in Ankara, Türkiye
- 🖥️  See my portfolio at [bayramalkan.com](https://www.bayramalkan.com/)
- ✉️  You can contact me at [bayramalkan1243@gmail.com](mailto:bayramalkan1243@gmail.com)
- 🧠  I'm going deeper into backend: NestJS, Postgres and edge runtimes like Cloudflare Workers
- 🤖  I build with AI agents every day — spec first, tests first, decision logs everywhere
- 🤝  I'm open to collaborating on React, Next.js and React Native projects
